# Kinetoglyphs

An ANSI/cell-art animation and sprite authoring tool, part of the **Telos** toolchain from Katabatic Vector.

Paint with glyphs and colour, animate across frames and layers, and export work that other Telos tools and games can consume directly. Single self-contained HTML file — no install, no account, no internet. Open `index.html` and make something.

Current build: v29.5.3.1.

Part of the suite:
- **Choros** — scene and space authoring
- **Katabasis** — behaviour and entity authoring
- **CALORIS** — sound engine and composition

Developed entirely on Android by Katabatic Vector, a one-person studio. More at https://katabatic-vector.itch.io
